# อีเมลต้อนรับผู้สมัครรับข่าวสาร

หัวข้อ: ขอบคุณที่สมัครรับข่าวสารจาก Smart Home Store
ข้อความพรีวิว: ไอเดียบ้านอัจฉริยะ สินค้าใหม่ และข่าวสารดี ๆ สำหรับคุณ — ชีวิตง่ายขึ้นด้วยเทคโนโลยี

- welcome-preview.html: เปิดดูในเบราว์เซอร์ได้ ใช้โลโก้และภาพที่มีอยู่ในโปรเจกต์ ปุ่มเข้าเว็บไซต์ชี้ไป localhost:3000
- welcome-newsletter.html: เทมเพลต HTML สำหรับระบบส่งอีเมล ต้องแทนค่าตัวแปรก่อนส่งจริง
- welcome-newsletter.txt: เนื้อหาแบบข้อความล้วนสำหรับส่งคู่ HTML

## ก่อนส่งจริง
แทน {{WEBSITE_URL}} ด้วย URL สาธารณะของร้าน (ไม่ใช่ localhost)
แทน {{LOGO_URL}} และ {{HERO_URL}} ด้วย URL HTTPS สาธารณะของภาพ
แทน {{PRIVACY_URL}} ด้วยหน้านโยบายที่เปิดอ่านได้จริง
แทน {{UNSUBSCRIBE_URL}} ด้วยลิงก์ยกเลิกเฉพาะผู้รับที่ระบบส่งอีเมลสร้างให้และทำงานได้จริง
ส่งเฉพาะผู้สมัครรับข่าวสารที่เลือกยินยอมด้านการตลาด ไม่ใช่สมาชิกทุกคนโดยอัตโนมัติ
ทดสอบอีเมลจริงใน Gmail/Outlook และมือถือก่อนใช้งาน เนื่องจากแต่ละแอปแสดง CSS ต่างกัน

ยังไม่ได้เชื่อมบริการส่งอีเมล ไม่ได้ส่งอีเมลถึงใคร และไม่ได้สร้างระบบยกเลิกข่าวสารในงานนี้
